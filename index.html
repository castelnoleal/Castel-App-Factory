Start with what you already have

If it works in a mobile browser, it can become an app.

An HTML file

A single page with its styles and scripts built in. Good for tools, calculators and small games.

A ZIP project

A full site folder with pages, images, fonts and scripts. It is bundled into the app so it can run offline.

A website link

Any HTTPS site you own or have permission to package. The app opens it with Android navigation built in.

Seven steps, one workspace

The app factory walks you through each step and saves your project in your browser, so you can stop and pick it up later.

  1. SourceUpload your file or ZIP, or enter a website link.
  2. DetailsName the app and set its package ID and version.
  3. IconAdd one square image. Every Android size is made for you.
  4. OfflineChoose whether the app keeps working without a connection.
  5. PreviewSee your app on a phone-sized screen before you build.
  6. CheckFix anything the pre-build checks flag.
  7. BuildDownload your APK and AAB when the build finishes.

Checked before it's built

Most rejected builds fail on small things. instApped looks for them first, so a build only starts when the project is ready for it.

  • Package IDValid format, and unique to your app.
  • Version name and codePresent, and in the form Google Play expects.
  • Target API levelSet to API 36, which Google Play requires for new apps and updates.
  • Icons and manifestEvery icon size present and the app manifest complete.
  • Source layoutAn entry page is found and the website link uses HTTPS.
  • Signing kept privateRelease keys stay in secure storage, never in your project files.

Questions

Do I need to know Android development?

No. instApped prepares the Android project and runs the build in the cloud. You need your web project, an app name and an icon.

What's the difference between the APK and the AAB?

The APK installs directly on a phone, so use it for testing. The AAB is the format Google Play requires when you publish. Both come from the same project.

Can I publish the app on Google Play?

Yes. Upload the AAB to your own Google Play Console account. You publish under your own developer name and are responsible for the store listing, content rating and the privacy disclosures Google Play asks for.

Who owns the app?

You do. You keep the rights to your content and to the app built from it. See the Terms of Service for details.

Will my app work offline?

HTML and ZIP projects are bundled into the app and can run fully offline. Website-link apps need a connection for pages that aren't already cached. You choose the offline setting in step four.

Is there a size limit?

Uploaded HTML and ZIP projects can be up to about 21 MB. Website-link apps have no upload limit, because the site is loaded rather than uploaded.

Can I package someone else's website?

Only if you have permission. Packaging sites or content you don't have the rights to is not allowed. See the Acceptable Use Policy.
