# Duel Synapse KodeX Android

Production Android wrapper for the standalone Duel Synapse KodeX engine.

- HTML master: `index.html`
- Package: `org.meiocg.duelsynapse.kodex`
- Target API: 36
- Minimum API: 24
- Online source: MEIOCG mirror at `cards.meiocg.org`
- Offline database: handled by the KodeX HTML/IndexedDB engine

The Android project is generated from the validated `android-template` in this repository by the KodeX CI workflow.
